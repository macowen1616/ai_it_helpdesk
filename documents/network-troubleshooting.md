# Network Troubleshooting

## Unable to Access Network Resources

If a computer cannot access a network resource, verify that the
computer has an active network connection.

Confirm that the user has permission to access the requested network
resource.

Check whether other users can access the same resource.

If multiple users cannot access the resource, the problem may be
related to the network service or server.

## Unable to Access Shared Files

If a user cannot access shared files or folders, verify that the
network connection is working.

Confirm that the user has the appropriate permissions for the shared
resource.

Verify that the network path or shared folder location is correct.

If the problem continues, determine whether other users are also
unable to access the shared files.
