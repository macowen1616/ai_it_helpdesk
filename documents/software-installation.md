# Software Installation

## Installing Software

Before installing software, verify that the software is approved by
the organization and that the user has permission to install it.

Download the software from the official or organization-approved
source.

Follow the installation instructions provided by the software vendor.

After installation, open the software and verify that it starts
correctly.

## Software Installation Fails

If a software installation fails, verify that the computer meets the
software's system requirements.

Check that the user has sufficient permissions to install software.

Verify that there is enough available storage space on the computer.

If the installation continues to fail, restart the computer and
attempt the installation again.

Check the installation error message for additional information.

## Software Will Not Open

If newly installed software will not open, restart the computer and
try launching the software again.

Verify that the software installation completed successfully.

Check whether the software requires an update.

If the problem continues, reinstall the software using the
organization-approved installation method.
