# Wi-Fi Troubleshooting

## Unable to Connect to Wi-Fi

If a computer cannot connect to a wireless network, verify that Wi-Fi
is enabled on the device.

Check that the correct wireless network is selected and that the user
has entered the correct password.

If the device still cannot connect, restart the computer and attempt
to connect again.

If other devices can connect to the network but the affected device
cannot, troubleshoot the affected device's wireless adapter.

## Connected but No Internet

If the computer is connected to Wi-Fi but cannot access the internet,
determine whether other devices on the same network have internet
access.

If multiple devices are affected, the problem may be related to the
network or internet connection.

If only one device is affected, restart the device and reconnect to
the wireless network.
