# Password Reset

## Forgotten Password

If a user has forgotten their password, use the organization's
approved password-reset process.

Verify the user's identity according to the organization's security
procedures before resetting the password.

After the password has been reset, the user should sign in with the
new password.

## Account Locked

If an account has been locked after multiple unsuccessful login
attempts, follow the organization's account-unlock procedure.

Verify the user's identity before unlocking the account.

The user should then attempt to sign in again using the correct
password.

## Password Not Working

If a user's password is not working, verify that the user is entering
the correct username and password.

Check whether Caps Lock is enabled and confirm that the user is using
the current password.

If the password has been forgotten, follow the approved password-reset
process.
