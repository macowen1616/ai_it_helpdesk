# Email Troubleshooting

## Unable to Send Email

If a user cannot send an email, verify that the computer has an
active internet connection.

Check that the recipient's email address is entered correctly.

Verify that the user's email account is connected and authenticated.

Check whether the user's mailbox is full.

If the problem continues, restart the email application and attempt
to send the message again.

## Unable to Receive Email

If a user cannot receive email, verify that the computer has an
active internet connection.

Check whether the mailbox is full.

Verify that the email application is connected to the user's account.

Check the spam or junk folder to determine whether the message was
filtered.

Restart the email application and check for new messages again.

## Email Application Not Working

If the email application is not responding, close and restart the
application.

Verify that the application is up to date.

Restart the computer if the problem continues.

If the application still does not work, determine whether the user
can access their email through the organization's approved webmail
service.
